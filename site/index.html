git blame tells you who. +git motive tells you why.

gitmotive records the prompt and reasoning behind every line an AI coding agent writes, then gives them back when you ask about that line. It runs on your machine. No LLM, no cloud, no account.

#The why ends with the session

AI agents now write more code than reviewers can absorb. Every line came from a prompt and a chain of reasoning, but that context lives in a chat window. When the session ends, it is gone.

Weeks later, git blame points to a commit and a person, who may not know why the line is there either. The commit message is one sentence. The thinking that produced the code was never saved.

gitmotive keeps those deleted lines.

#How it works

  1. Install the CLI

    $ pipx install gitmotive

    Python 3.10 or newer. No runtime dependencies.

  2. Hook up your agent, once per repo

    $ gitmotive install --agent claude

    Adds the agent's hooks and a git post-commit hook, and keeps .gitmotive/ out of git. Then use your agent as usual.

  3. Ask any line why it exists

    $ git motive path/to/file.py:42

    Prints the prompt, the agent's reasoning, the session, the model and the commit. If no hook saw the edit, it says none recorded instead of guessing.

#Install

With pipx

$ pipx install gitmotive

Without pipx

$ curl -fsSL https://gitmotive.tech/install.sh | sh

Creates a venv in ~/.gitmotive/venv and puts gitmotive and git-motive in ~/.local/bin. Read the script first if you like; it is plain shell.

#Nothing is guessed

deterministic
Lines are matched to edits through git blame and the recorded edit text. No model reads your code.
local
Events are append-only JSONL in .gitmotive/, or under ~/.gitmotive/ with --scope user. No network calls, no telemetry.
open source
MIT licensed. Read the code, file an issue or send a patch on GitHub.
